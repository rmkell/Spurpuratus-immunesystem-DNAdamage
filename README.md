# Transcriptomic analysis of sea urchin (S. purpuratus) immune system cells (coelomocytes): Response to DNA damage
Raw data for the single-cell and bulk RNA sequencing have been deposited in the National Center of Biotechnology Information (NCBI) under BioProject accession number PRJNA1346447 (Sequence Read Archive accession numbers SRR35853817 – SRR35853834). 

# Single-cell RNA sequencing #
* Single-cell RNA sequencing was performed on S. purpuratus coelomocytes harvested at 6hrs post-UVB dose.
* 10,000 cells from each n=3 biological replicates of each condition were prepared with the 10x Genomic Chromium Next GEM Single Cell 3' v3.1 protocol following the manufacturer’s instructions.
* Single cell cDNA libraries were prepared using the Chromium Single Cell 3′ Reagent Kit v3 Chemistry.
* Libraries were sequenced on an Illumina NovaSeq 6000 (SP 200 cycle kit, v1.5).
* Bioinformatic analysis of the data can be found in the "SingleCell_RNAseq" folder above.
* Single cell extraction, library preparation and analysis were performed by Riss Kell. Single cell sequencing was performed by the Center for Genome Innovation (CGI) at the University of Connecticut (UCONN)

# Bulk mRNA sequencing #
* Bulk mRNA sequencing was performed on S. purpuratus coelomocytes harvested at 0, 1, 3, 6, and 24hrs post-UVB dose.
  * 3 bio replicates * 2 conditions * 5 timepoints = 30 total samples
* Total RNA was extracted from each harvested cell pellet using the RNeasy® Plus Mini Kit (Qiagen) following the manufacturer’s instructions.
* mRNA pulldown and cDNA libraries were prepared using a Takara Low Input mRNA SMART-Seq LP kit and sequenced on an Illumina NovaSeq 6000 (NovaSeq S4 200 cycle kit), targeting 50M total paired-end reads per sample; 100bp PE.
* Bioinformatic analysis of the data can be found in the "BulkRNAseq" folder above.
* Total RNA extraction, QC, and analysis was performed by Riss Kell.
* mRNA pulldown and cDNA library preparation were performed by the Center for Genome Innovation (CGI) at the University of Connecticut (UCONN)
